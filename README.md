# 轻迁 MoveLite

**给下一站，留点空间。** 面向毕业跨城、换小户型和临时急搬的个人物品决策应用。

[打开网页](https://xf-png.github.io/movelite-ai/) · [商业模式与竞品分析](docs/商业模式与竞品分析.md) · [简历项目说明](docs/简历项目说明.md)

**当前定位：可运行的技术演示，消费需求尚未验证。** 2026-10-22 的使用场景反馈指出：用户可以在整理时直接决定物品去留，事前录入体积、价格和耗时可能增加负担。此前按次收费的设想没有需求证据。项目保留工程实现和测试，产品判断以 [需求复盘](docs/需求复盘.md) 为最新说明。

输入新家容量、处理闲置的时间和车型报价，比较“多留一点”“少花一点”“快一点”三种去留方案。锁定重要物品，查看每个决定的依据，再按行动清单执行和记录实际到账金额。

## 业务切口

同类已覆盖 AI 识物、家庭库存、去留分组和搬家清单。MoveLite 选择的重点是**容量、时间与人工锁定约束下的组合决策，以及决定后的执行记录**。竞品对比以 2026-10-22 的官方公开页面为依据，不声称首创或市场空白。

当前网页免费体验。原先的商业假设是针对一次搬家项目测试 ¥9.9 / ¥19.9 的付费意愿，但输入成本与替代方案尚未验证，这两档价格仅作为历史设想记录。尚未接入收款、交易撮合或家庭云协作，也没有真实付费或营收数据。研究依据和原先的验证计划见商业文档，最新需求判断见需求复盘。

## 完整体验

1. 打开网页，体验“毕业跨城搬家”“换到小户型”或“三天内急搬”的虚构示例。
2. 调整可带走容量、处置可用时间和车型固定报价，比较三种方案。
3. 点击物品旁的锁，固定带走；在物品编辑中也可锁定其他去向。超限时明确提示无可行方案。
4. 开始自己的计划，粘贴物品清单，逐项确认体积、价格、耗时和重要程度。未确认草稿不进入求解。
5. 可启用浏览器本地 AI，为草稿建议类别。首次约下载 47 MB，资料不上传；不确定项保留“其他”。
6. 在行动清单标记完成、记录真实到账金额，导出未完成行动日历或 Markdown 方案。
7. 主动开启本地保存，或导出 JSON 备份，方便刷新恢复及迁移。

示例物品、初始体积、转让金额、耗时和车型报价均是假设，不是市场价或搬家公司实时报价。正式使用前应替换为自己的估计和获得的报价。

## AI 与计算各自负责什么

- **规则解析**：将逐行/分号输入整理成草稿，支持数量、每件与整组体积、升/立方米和明确填写的转让价。缺失体积的参考值须人工确认，缺失价格不会由模型估算。
- **真实 AI 语义分类**：BGE 中文向量模型比较物品描述与类别原型。仅修改类别和分类来源，不改体积、金额、锁定、确认或其他人工字段。低相关或候选接近时回退“其他”。
- **多约束求解**：二维多选择动态规划在容量与处置时间限制内，为每组选择带走、转让、转赠或回收处理，分别计算三种偏好倾向。
- **执行闭环**：已完成行动固定去向；已成交金额独立记录，不将预计转让收入写成实际到账。编辑和恢复前校验整个工作区的一致性。

本项目没有生成式大语言模型、对话代理或市场价格预测。转让文案由用户已有信息整理为模板，不自动发布、联系他人或预订服务。

## 约束与费用

| 项目 | 范围与含义 |
| --- | --- |
| 物品 | 最多 40 组；每条整组处理，数量不重复乘入体积、金额或耗时 |
| 容量 | 设置最多 10,000 升，即 10 m³ |
| 处置时间 | 最多 720 分钟，带走物品的打包时间另行安排 |
| 分档 | 每组体积向上取整到 10 升，处置时间向上取整到 5 分钟，预算向下分档 |
| 不可行方案 | 超限、损坏物品锁定转让/转赠、零意向价锁定转让、车型容量不足等情况会说明原因 |
| 车型 | 按规划体积选择能装下的最低固定报价；不会声称少带一件就按比例省运费 |
| 金额 | 预计净支出 = 车型报价 + 处理费用 − 意向转让收入；可以为负数，表示假设成交下的预计结余 |
| 实际记录 | 实际收入只关联已完成转让；取消完成时确认移除对应记账，可撤销恢复 |

目标权重属于可解释的偏好规则，不是市场价值、学习到的准确率或货币效用。算法求解的是上述保守分档模型；离散化可能排除某些实际可行的边界组合，不能称为连续原问题的全局最优。

## 本地运行

完整源码包已包含模型、分词器、WASM 和许可证。需要 Python 3，Windows 可双击 `启动应用.cmd`；也可以在项目目录运行：

```sh
python tools/serve.py
```

脚本只在本机启动静态服务并打开浏览器，默认地址为 `http://127.0.0.1:4173`，占用时依次尝试至 4182，以终端打印地址为准。关闭服务窗口即停止。无需前端构建、npm 安装、API Key 或后端数据库。

页面使用 ES Modules 和 Web Worker，应经 HTTP/HTTPS 访问，不能直接双击 HTML。公开网页未实现离线应用缓存，不承诺断网后重新打开网页可用。

## 保存与隐私

本地保存默认关闭。主动开启后，工作区写入当前浏览器的 localStorage；失败时不会假称保存成功。清除站点数据、无痕窗口或换设备会影响恢复，应自行保留备份。

JSON 备份包含物品、约束、完成状态和实际金额，最大 1 MB；恢复时校验版本、字段、编号、日期、去向和记账一致性。它不包含模型或向量缓存。Markdown 用于方案记录，ICS 仅导出未完成的全天行动事件；导入日历不代表已经预约服务。

物品文字、求解和模型推理均在浏览器内进行。首次启用 AI 从本站下载约 47 MB 公开资源，网站托管商仍可能记录普通访问日志；模型请求不会携带物品描述。

## 实现与发布

```text
dist/
  app.js / index.html / styles.css  工作台、确认、比较、行动与保存界面
  engine.js                        规范化、约束与二维动态规划
  optimizer.worker.js              独立求解 Worker
  inventory.js                     草稿、语义分类、备份、日历与文案
  model.js                         独立本地模型 Worker、取消和超时
  demo.js                          三个可复现的虚构场景
  models/ / vendor/ / licenses/     固定模型、运行文件与第三方许可
tests/                             引擎和库存业务检查
tools/                             本地服务与资源完整性校验
docs/                              商业模式、简历描述与验证记录
```

GitHub Actions 检查通过后，将完整 `dist/` 发布到 Pages。必须上传模型和运行目录，不能只发布顶层页面文件。浏览器模块、Worker 与模型地址使用相对路径，适配 `/movelite-ai/` 子目录；变更发布版本时应同步更新入口版本参数。

运行组件：Transformers.js 3.8.1、ONNX Runtime Web/WASM，模型为 `Xenova/bge-small-zh-v1.5` 修订 `75c43b069aac4d136ba6bc1122f995fedcfd2781`，q8 权重约 24 MB，CLS 池化与 512 维归一化输出。第三方资源按原样分发，许可与来源见 [THIRD_PARTY_NOTICES](dist/THIRD_PARTY_NOTICES.md)。
